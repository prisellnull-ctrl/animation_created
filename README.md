# Пиксель-мульт

Редактор пиксельных мультиков для телефона: сценарий текстом, свои PNG-персонажи, запись видео.

## Публикация на GitHub Pages
1. Создай репозиторий (например `pixmult`), загрузи в корень все файлы этой папки.
2. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
3. Через минуту сайт будет по адресу `https://<логин>.github.io/pixmult/`.
4. На iPhone открой его в Safari → «Поделиться» → «На экран „Домой“».

При обновлении `index.html` подними версию в `sw.js` (сейчас `pixmult-v3`, дальше v4…), чтобы телефон подтянул новую.
